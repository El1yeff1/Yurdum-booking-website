# 🏡 Yurdum | Motion-Driven Property Rental Platform

"Yurdum" is a modern, concept-driven property rental web application inspired by Airbnb, built with a heavy focus on **fluid motion design**, micro-interactions, and seamless UI/UX transitions. 

https://yurdum.vercel.app/

This demo showcases how advanced animations and smooth state changes can elevate a standard booking platform into an immersive, premium user experience.

## ✨ Key Features
- **Motion & Micro-interactions:** Smooth page transitions, hover effects, and animated components powered by modern design principles.
- **Airbnb-Inspired UX:** Clean, minimalist layout tailored for property browsing, filtering, and seamless discovery.
- **Responsive Design:** Optimized for both desktop and mobile viewports with fluid scaling.
- **Interactive Demos:** Fully functional UI states for booking previews, image galleries, and listing cards.
